# Infografías

Directrices para subir infografías:
- Incluye siempre un archivo metadata con el mismo nombre base (ej.: infografias/posicion_lateral_segura.svg y infografias/posicion_lateral_segura_metadata.md).
- Aporta una versión en alta resolución y una versión optimizada para web.
- Incluye alt text dentro del metadata para accesibilidad.
- Señala las fuentes de las imágenes y permisos.

Ejemplo de nombre de archivo:
- infografias/posicion_lateral_segura_1200x800.svg
