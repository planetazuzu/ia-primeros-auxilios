# Cómo contribuir a "IA para Primeros Auxilios"

Gracias por querer contribuir. A continuación encontrarás pasos sencillos para participar, tanto si usas Git como si no.

1) Antes de contribuir
- Revisa el README.md y la estructura de carpetas.
- Asegúrate de que tu aporte esté permitido para ser publicado bajo CC BY-SA 4.0 o que eres el titular de los derechos y aceptas licenciar bajo CC BY-SA 4.0.

2) Preparar tu aporte
- Añade metadatos en un archivo .md con la misma base de nombre:
  - título, autores, fecha, licencia, fuentes, idioma, accesibilidad, notas de uso.
- Usa nombres de archivo descriptivos y normalizados (minúsculas, guiones, sin espacios).

3) Si sabes usar Git / GitHub (recomendado)
- Forkea el repositorio.
- Crea una rama con nombre descriptivo: feat/mi-aporte, fix/actualizar-rcp, add/infografia-quemaduras
- Añade tus archivos en la carpeta correspondiente.
- Crea un Pull Request describiendo:
  - Qué aportas
  - Fuentes y referencias
  - Nivel de revisión solicitado (básico / revisión experta)
- Mantén la conversación en el PR y responde a comentarios de revisores.

4) Si no usas Git
- Prepara tus archivos y el metadata .md
- Envía un correo a contacto@ia-primeros-auxilios.org con:
  - Archivos adjuntos o enlace a almacenamiento (Google Drive/Dropbox) con permisos de descarga pública.
  - Indica la carpeta destino sugerida y proporciona la metadata.
- Alternativamente, abre un issue (si tienes cuenta GitHub) y pega la información + enlace de descarga.

5) Revisión y aceptación
- Los mantenedores revisarán la conformidad con licencias, evidencias y formatos.
- Es posible que pidamos cambios para accesibilidad o referencias.
- Una vez aceptado, integraremos el recurso al repositorio (PR merge o subida por mantenedor).

6) Buenas prácticas y seguridad
- No subas información que incluya datos personales identificables o sensibles sin consentimiento y anonimización.
- Evita instrucciones que puedan suponer riesgo si se aplican incorrectamente; añade siempre advertencias para buscar ayuda profesional y llamar a servicios de emergencia locales.

7) Créditos y atribución
- Mantén la información de autoría dentro del recurso y metadata.
- Al contribuir aceptas licenciar tu aporte bajo CC BY-SA 4.0 salvo que indiques otra licencia compatible y explícita.

Contacto para dudas

¡Gracias por tu contribución!
