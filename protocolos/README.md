Carpeta 'protocolos'

Protocolos clínicos y procedimientos estandarizados. Guardar versiones en texto (Markdown) y mantener metadatos para cada protocolo.

Normas:
- Cada protocolo debe contener un archivo de metadatos 'ejemplo-protocolos.md' con la ficha del protocolo.
- No añadir binarios; use enlaces para documentos externos.
