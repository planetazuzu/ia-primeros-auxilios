Carpeta 'documentos'

Aquí van documentos de texto, guías en formato markdown o referencias que no sean archivos binarios. Incluye resúmenes, informes y fichas técnicas relacionadas con primeros auxilios. No subir archivos binarios (pdf, docx) a este repositorio; en su lugar, use enlaces en el archivo de ejemplo.

Normas:
- Solo archivos de texto (markdown) y metadatos.
- Use el archivo ejemplo 'ejemplo-documentos.md' como plantilla.
- Mantener idioma: es
