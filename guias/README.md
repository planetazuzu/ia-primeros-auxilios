Carpeta 'guias'

Aquí van guías prácticas y tutoriales en formato texto (preferiblemente Markdown) relacionados con primeros auxilios y procedimientos. Las guías deben ser documentos explicativos, con pasos, ilustraciones referenciadas mediante enlaces y metadatos.

Normas:
- Textos en español preferentemente.
- No subir binarios (imágenes o PDFs); use enlaces si es necesario.
- Cada guía puede incluir un archivo de metadatos 'ejemplo-guias.md' siguiendo el formato estándar.
